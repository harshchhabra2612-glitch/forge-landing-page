# Forge — Code Review & CI Landing Page

A high-performance, dark-mode landing page for **Forge**, built with React 18, TypeScript, and Vite.

## Features

- **Interactive Hero & Terminal**: Real-time typing animation with customizable command output.
- **Scroll-Scrubbed Timeline**: Dynamic PR progression line that draws with scroll.
- **Annotated Diff Inspector**: Review comments with pop-in transitions and inline suggestion commitments.
- **90-Second Merge Scene**: Sticky scroll-scrubbed job pipeline and live gantt chart.
- **Live Micro-Visual Bento Grid**: Real-time simulated stack transitions and metrics.
- **Interactive Hairline Integrations Grid**: Cursor-follow spotlight effect across integration borders.
- **Pricing Calculator**: Interactive per-seat cost calculation with live slider updates.
- **Accessibility & Performance**: Built with responsive layouts, reduced-motion fallbacks, and prefers-contrast support.

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm, yarn, or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/harshchhabra2612-glitch/forge-landing-page.git

# Navigate to project directory
cd forge-landing-page

# Install dependencies
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
